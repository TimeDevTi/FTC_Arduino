# หุ่นล้อ Mecanum ควบคุมผ่านเว็บ ด้วยสาย USB และรีโมท FlySky (Arduino Mega 2560)

```
คอมพิวเตอร์ (Chrome / Edge เปิด Mecanum_Control.html) ──สาย USB──┐
                                                                ▼
รีโมท FlySky (iBUS สัญญาณเข้าขา 19) ─────────────────────────► Arduino Mega ──► ไดรเวอร์มอเตอร์ ──► มอเตอร์ 4 ตัว
```

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `platformio.ini` | ไฟล์คอนฟิก PlatformIO ตั้งค่าสำหรับบอร์ด **Arduino Mega 2560** (`megaatmega2560`) |
| `src/main.cpp` | ซอร์สโค้ดเฟิร์มแวร์ C++ สำหรับคอมไพล์และอัปโหลดผ่าน **PlatformIO** |
| `Mecanum_Control.html` | หน้าเว็บควบคุม เปิดด้วย Chrome หรือ Edge (ไม่ต้องใช้อินเทอร์เน็ต) |
| `Arduino_Mecanum_USB/Arduino_Mecanum_USB.ino` | โค้ดสำหรับเปิดและอัปโหลดด้วย **Arduino IDE** |

- หน้าเว็บส่งคำสั่งผ่านสาย USB (Web Serial) ทุก 50 ms
- หรือคุมผ่านรีโมท FlySky (iBUS) เสียบสายสัญญาณเส้นเดียวเข้าขา 19 (RX1)
- Arduino คำนวณความเร็ว 4 ล้อแบบ mecanum เอง เร่ง/เบรกแบบนุ่มนวล และเก็บค่าตั้งล้อไว้ใน EEPROM
- ไม่ต้องลง library หรือโปรแกรมเพิ่ม พัฒนาและจัดการโปรเจกต์ด้วย **PlatformIO**

## 1. การต่อสาย

บอร์ดที่ใช้: **Arduino Mega 2560** (ขา 2–13 เป็น PWM ทุกขา)

- สาย **USB** จาก Arduino → คอมพิวเตอร์ (เฉพาะตอนใช้หน้าเว็บ / อัปโหลด)
- **ขา 0 / 1 ห้ามต่ออะไร** เพราะเป็นขาเดียวกับสาย USB
- **GND ของ driver ทุกตัวต่อร่วมกับ GND ของ Arduino**
- มอเตอร์ใช้ไฟจากแบตผ่าน driver (ห้ามดึงไฟมอเตอร์จาก 5V ของ Arduino)

| ช่อง | ขา Mega | ต่อกับ driver |
|---|---|---|
| M1 | D2, D3 | IN1, IN2 ของ driver มอเตอร์ตัวที่ 1 |
| M2 | D4, D5 | IN1, IN2 ของ driver มอเตอร์ตัวที่ 2 |
| M3 | D6 → **AIN1**, D7 → **AIN2** | TB6612 ช่อง A (มอเตอร์ต่อ AO1, AO2) |
| M4 | D8 → **BIN1**, D9 → **BIN2** | TB6612 ช่อง B (มอเตอร์ต่อ BO1, BO2) |

**TB6612 ต่อเพิ่ม**

| ขา TB6612 | ต่อกับ |
|---|---|
| PWMA, PWMB, STBY, VCC | 5V ของ Arduino |
| VM | ขั้วบวกแบตมอเตอร์ (4.5–13.5V) |
| GND | ขั้วลบแบตมอเตอร์ และ GND ของ Arduino |

- ไม่ต้องกังวลว่าช่องไหนต่อล้อไหน หรือหมุนกลับทาง ตั้งได้จากหน้าเว็บ (ข้อ 4)
- TB6612 รับกระแสต่อเนื่องได้ประมาณ 1.2A ต่อช่อง (สูงสุดชั่วขณะ 3.2A) ถ้ามอเตอร์กินกระแสมากกว่านี้ตอนล้อติด ชิปอาจเสียได้
- ชนิด driver และขาของแต่ละช่องตั้งได้ใน `MOTORS[]` ในโค้ด (`PWM_DIR` หรือ `IN1_IN2`)
- L298N (ถ้าใช้กับ M1/M2): ต้อง**เสียบจัมเปอร์ ENA/ENB ไว้**

**ไฟ D13 บน Arduino**: ติดค้าง = ได้รับคำสั่ง (รีโมทหรือเว็บ) · กะพริบช้าๆ = รอคำสั่ง (มอเตอร์หยุด)

## 2. คอมไพล์และอัปโหลดโค้ด

### วิธีที่ 1: ผ่าน PlatformIO (แนะนำ)

โปรเจกต์ตั้งค่าพร้อมใช้งานสำหรับ **Arduino Mega 2560** ใน `platformio.ini` เรียบร้อยแล้ว:

```bash
# คอมไพล์โค้ด
pio run

# อัปโหลดลงบอร์ด Arduino Mega 2560
pio run -t upload

# เปิด Serial Monitor (115200 baud)
pio device monitor -b 115200
```

### วิธีที่ 2: ผ่าน Arduino IDE
เปิด `Arduino_Mecanum_USB/Arduino_Mecanum_USB.ino` → ไปที่เมนู Tools > Board > **Arduino AVR Boards > Arduino Mega or Mega 2560** → กด Upload

> **ข้อสำคัญ**: ก่อนเปิดหน้าเว็บ `Mecanum_Control.html` ให้ปิด Serial Monitor ใน PlatformIO หรือ Arduino IDE ก่อนเสมอ เพราะพอร์ต USB เชื่อมต่อได้ทีละโปรแกรม

## 3. ใช้งานหน้าเว็บควบคุม

1. ดับเบิลคลิก `Mecanum_Control.html` ให้เปิดด้วย **Google Chrome** หรือ **Microsoft Edge**
2. กดปุ่ม **เชื่อมต่อ** → เลือกพอร์ตของ Arduino Mega (เช่น "USB-SERIAL CH340 (COM...)" หรือ "/dev/ttyUSB0") → Connect
3. รอ 1–2 วินาที (Arduino รีเซ็ตตอนเปิดพอร์ต) จุด **USB** และ **Arduino** จะเป็นสีเขียว
4. แท็บ **ขับ**
   - จอยซ้าย (ลากด้วยเมาส์): เดินหน้า / ถอยหลัง / สไลด์ / เฉียง
   - แถบขวา: หมุนตัวอยู่กับที่
   - คีย์บอร์ด: `W A S D` หรือลูกศร = เดิน/สไลด์, `Q E` = หมุน, `Space` = หยุด
   - แถบความเร็ว 10–100%
5. ครั้งต่อไปที่เปิดหน้าเว็บ อาจต่อให้อัตโนมัติ (ถ้าเบราว์เซอร์จำสิทธิ์พอร์ตไว้)

ทดลองหน้าเว็บโดยไม่ต่อหุ่น: เปิด `Mecanum_Control.html?demo`

## 4. ตั้งค่าล้อครั้งแรก (สำคัญ)

1. **ยกหุ่นให้ล้อลอยจากพื้น**
2. ไปแท็บ **ตั้งค่าล้อ**
3. กดค้าง **▲ หน้า** ที่การ์ด "ซ้ายหน้า" แล้วดูว่าล้อไหนหมุน
   - ถ้าไม่ใช่ล้อซ้ายหน้า → เปลี่ยน **ช่องมอเตอร์**
   - ถ้าหมุน**ถอยหลัง** → ติ๊ก **กลับทิศ**
4. ทำแบบเดียวกันอีก 3 ล้อ (ห้ามมีช่องซ้ำ เว็บจะเตือน)
5. **ปรับความเร็วให้เท่ากัน**: กดค้าง **▲ ทดสอบทุกล้อพร้อมกัน** แล้วดูว่าล้อไหนหมุนเร็วกว่า
   → ลดแถบ **ความแรง** ของล้อนั้น (30–100%) จนทุกล้อหมุนเร็วพอๆ กัน
   (ถ้าใช้ driver คนละรุ่น ความเร็วมักไม่เท่ากัน เพราะแต่ละรุ่นเสียแรงดันไม่เท่ากัน)
6. กด **บันทึก** ค่าจะเก็บใน EEPROM ของ Arduino (ถอดสายแล้วยังอยู่ ใช้กับคอมเครื่องไหนก็ได้)

> ถ้าเดินหน้าและหมุนถูก แต่**สไลด์ไม่ได้** → ติดล้อสลับ:
> **มองจากด้านบน ลูกกลิ้งของ 4 ล้อต้องเรียงเป็นรูปตัว X** (เหมือนรูปหุ่นในหน้าเว็บ)

## 4.5 รีโมท FlySky (iBUS)

**ต่อสายรีซีฟ** (เช่น FS-iA6B ใช้พอร์ต **iBUS / SERVO**)

| รีซีฟ | Arduino Mega 2560 |
|---|---|
| สัญญาณ iBUS | **ขา 19 (RX1)** |
| + | 5V |
| − | GND |

> ⚠️ **บน Mega อย่าต่อรีซีฟที่ขา 0**: ขา 0 ใช้ร่วมกับ USB หากต่อไว้จะอัปโหลดไม่ได้ หน้าเว็บสั่งไม่ได้ และตอนเปิดเครื่องอาจค้างใน bootloader

**คันบังคับ** (ค่าเริ่มต้น รีโมท FS-i6 / FS-i6X แบบ Mode 2)

| ช่อง | คัน | หน้าที่ |
|---|---|---|
| CH1 | คันขวา ซ้าย-ขวา | สไลด์ซ้าย/ขวา |
| CH2 | คันขวา ขึ้น-ลง | เดินหน้า/ถอยหลัง |
| CH4 | คันซ้าย ซ้าย-ขวา | หมุนตัว |
| CH3 | คันซ้าย ขึ้น-ลง (คันเร่ง) | ความเร็วสูงสุด: ล่างสุด = 30%, บนสุด = 100% |

- ดูค่าแต่ละช่องสดๆ ได้ในหน้าเว็บ แท็บ **ตั้งค่าล้อ** การ์ด "รีโมท FlySky" (การ์ดจะบอกด้วยว่าสายมีปัญหาตรงไหน)
- คันทิศกลับ: กลับที่รีโมท (FS-i6: Functions setup → Reverse) หรือแก้ `RC_REV_X/Y/R` ในโค้ด
- เปลี่ยนช่องได้ที่ `RC_CH_X`, `RC_CH_Y`, `RC_CH_R`, `RC_CH_SPEED` ในโค้ด
- สวิตช์ "เปิดให้ขับ": ตั้ง `RC_CH_ARM = 5` (หรือช่องสวิตช์ที่ใช้) สวิตช์ต้องเกิน 1700 ถึงจะขับได้

> ⚠️ **ต้องตั้ง Failsafe ที่รีโมท** (FS-i6: Functions setup → Failsafe)
> ตั้ง CH1, CH2, CH4 ให้ "On" ที่ **ตำแหน่งกลาง** (ถ้าใช้สวิตช์เปิดขับ ให้ตั้งช่องนั้นเป็น "ปิด")
> ถ้าไม่ตั้ง เมื่อรีโมทดับหรือหลุดระยะ รีซีฟจะส่งค่าล่าสุดค้างไว้ หุ่นจะวิ่งต่อ

**ใครคุมหุ่น** (เรียงตามลำดับ): ปุ่มทดสอบล้อในเว็บตอนกดค้าง → รีโมท → จอยในเว็บ (ใช้ได้ตอนปิดรีโมท)

**ใช้รีโมทโดยไม่ต่อคอม**: ถอดสาย USB ได้เลย แต่ Arduino ต้องมีไฟเลี้ยง เช่น แบต 7–12V เข้าแจ็ค DC หรือขา VIN

## 5. ระบบความปลอดภัย

- Arduino ไม่ได้รับคำสั่งเกิน 0.5 วินาที → หยุดเอง ครอบคลุมกรณี: ถอดสาย USB, ปิดหน้าเว็บ, ย่อหน้าต่าง/สลับแท็บ, คอมค้าง
- หน้าเว็บรอให้ Arduino บูตเสร็จก่อนค่อยส่งคำสั่ง
- เร่งและเบรกแบบนุ่ม (ramp) กันหุ่นกระตุกหรือหงาย

## 6. ทดสอบด้วย Serial Monitor (ไม่ต้องใช้หน้าเว็บ)

Serial Monitor → **115200** baud, ท้ายบรรทัด **Newline** แล้วพิมพ์

| คำสั่ง | ผล |
|---|---|
| `T 0 150` | ล้อซ้ายหน้า (FL) หมุนเดินหน้าครึ่งวินาที |
| `D 0 50 0` | ทั้งหุ่นเดินหน้า 50% ครึ่งวินาที |
| `G` | ดูค่าตั้งล้อ |

คำสั่งเดียวหมุนแค่ครึ่งวินาที เพราะระบบหยุดอัตโนมัติ (หน้าเว็บส่งซ้ำทุก 50 ms จึงหมุนต่อเนื่อง)

## 7. ค่าที่ปรับได้ในโค้ด (`src/main.cpp` ส่วน "ตั้งค่า")

| ค่า | ความหมาย |
|---|---|
| `MOTORS[]` | ขาและชนิด driver ของแต่ละช่อง: `{ขา A, ขา B, PWM_DIR หรือ IN1_IN2}` |

| `BAUD` | 115200 ถ้าแก้ ต้องแก้ `BAUD` ในไฟล์ HTML ด้วย |

| การ์ดรีโมท: "ข้อมูลเพี้ยน" | สายหลวม/ยาว หรือแรงดันสัญญาณต่ำ |
| หุ่นวิ่งต่อตอนปิดรีโมท | ยังไม่ได้ตั้ง Failsafe ที่รีโมท (ข้อ 4.5) |

## 9. โปรโตคอล (สำหรับแก้โค้ดต่อ)

**เว็บ → Arduino** (ข้อความทีละบรรทัด, 115200)

| ข้อความ | ความหมาย |
|---|---|
| `D x y r` | ขับ: x = สไลด์ขวา, y = เดินหน้า, r = หมุนตามเข็ม (−100..100) |
| `T w v` | ทดสอบล้อ w (0=FL 1=FR 2=RL 3=RR, 4 = ทุกล้อ, −1 = ไม่มี) ความเร็ว v (−255..255) |
| `S` | หยุด |
| `C m0..m3 i0..i3 g0..g3` | ตั้งช่องมอเตอร์ (0..3) / กลับทิศ (0/1) / ความแรง (30..100 %) ของ FL FR RL RR |
| `W` / `G` | บันทึกลง EEPROM / ขอค่าปัจจุบัน |

**Arduino → เว็บ** (JSON ทีละบรรทัด)
- ทุก 100 ms: `{"w":[FL,FR,RL,RR],"s":ผู้คุม}` ความเร็วแต่ละล้อ (−255..255), ผู้คุม 0 ไม่มี / 1 รีโมท / 2 เว็บ / 3 ทดสอบ
- ทุก 100 ms: `{"rc":[สัญญาณ,เปิดขับ,เฟรมดี,เฟรมเสีย,ไบต์],"ch":[CH1..CH8]}` สถานะรีโมท
- ตอนบูต: `{"ready":1}`
- ค่าใน `w` คือค่าที่สั่งมอเตอร์จริงหลังปรับความแรงแล้ว
- ตอบ `C` / `W` / `G`: `{"cfg":{"m":[..],"v":[..],"g":[..]},"saved":0|1}`

**สูตร mecanum**
```
FL = y + x + r      FR = y − x − r
RL = y − x + r      RR = y + x − r
```
ถ้าค่าใดเกิน 100 จะย่อทุกล้อด้วยอัตราส่วนเดียวกัน แล้วแปลงเป็น PWM 0–255
